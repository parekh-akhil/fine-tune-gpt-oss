# Data Directory

This directory contains the training data for fine-tuning GPT OSS 20B.

## Structure

- **raw/**: Place your raw data files here (JSON, JSONL, CSV)
- **processed/**: Processed data ready for training (generated by `prepare_data.py`)

## Data Format

Your raw data should contain instruction-response pairs. The following formats are supported:

### JSONL Format (Recommended)
```json
{"instruction": "Your question or instruction", "response": "The expected response"}
{"instruction": "Another instruction", "response": "Another response"}
```

### JSON Format
```json
[
  {"instruction": "Your question", "response": "The expected response"},
  {"instruction": "Another question", "response": "Another response"}
]
```

or with a data wrapper:
```json
{
  "data": [
    {"instruction": "Your question", "response": "The expected response"}
  ]
}
```

### CSV Format
```csv
instruction,response
"Your question","The expected response"
"Another question","Another response"
```

## Creating Quality Training Data

### Best Practices

1. **Human-like Responses**: Ensure responses are natural, conversational, and helpful
2. **Diverse Topics**: Cover a wide range of topics and question types
3. **Consistent Tone**: Maintain a consistent voice and style across responses
4. **Appropriate Length**: Aim for 50-500 tokens per response
5. **Accurate Information**: Ensure responses are factually correct

### Example: Good vs. Bad

**Good Response:**
```json
{
  "instruction": "What is photosynthesis?",
  "response": "Photosynthesis is the amazing process plants use to make their own food! Here's how it works: plants take in carbon dioxide from the air and water from the soil, then use sunlight as energy to convert these into glucose (sugar) and oxygen. The oxygen is released back into the air, which is great for us because we breathe it! This process mainly happens in the leaves, specifically in tiny structures called chloroplasts that contain chlorophyll - the green pigment that gives plants their color."
}
```

**Poor Response:**
```json
{
  "instruction": "What is photosynthesis?",
  "response": "Process where plants make food."
}
```

## Preparing Your Data

Use the preparation script to convert your raw data:

```bash
python scripts/prepare_data.py \
    --input data/raw/your_data.jsonl \
    --output-dir data/processed \
    --eval-ratio 0.1
```

This will:
- Validate and format your data
- Split into training and evaluation sets
- Save in the correct format for training
